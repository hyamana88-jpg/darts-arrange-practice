# コード・JSON確認結果

確認対象は元の全7ファイル（HTML、CSS、app.js、JSON、manifest、Service Worker、README）。フレームワーク、依存パッケージ、ビルド、既存テスト、CI、AGENTS.mdはありませんでした。

## 修正した問題

- JSONはルートに存在するのに、アプリとキャッシュは存在しない `data/` を参照。通常の静的配信で読み込みとSWインストールが失敗。
- DO: 9、25、121、133、139の5ルートは合計点不一致。121はトリプル終了にもなっていた。
- MO: 87は合計83点。128は `D,D,D14` という不正トークンと合計点不一致。
- `B`/`DB`/`BULL` の表記が不統一。実行時に50点の `BULL` へ正規化。DOのインナーブル終了を認め、MO/SOでSB（25点）を入力できないようにした。
- 候補はトークン形式だけを確認していた。合計、3本以内、途中のバースト、最後のアウト条件を純粋関数で検証する構成へ分離。
- DO/MOの1残りをバーストとして扱い、確定後の追加入力を禁止。戻す・クリアは成績も取り消す。
- 自分アレンジは無検証で保存し、HTMLに埋め込んでいた。新規登録と既存保存データの読み込み時に合法ルートを検証し、重複を防止。既存保存キーは継続使用。
- README記載のPagesワークフロー、CODEX_PROMPT.mdは実在しなかった。ドキュメントを実際の構成に更新。
- manifestにアイコンがなかった。iPhone用180px、192/512pxアイコンを追加。
- SWは全キャッシュを削除し、失敗したJSONや画像にもHTMLを返していた。アプリとスコープに限定したキャッシュ管理・ナビゲーションだけのHTMLフォールバックへ変更。

## データの確認範囲

2〜180の179行が重複なく連続すること、全非空ルートが合法なこと、空ルートは3本では上がれないことをテスト。DOの121〜170は43点数（159、162、163、165、166、168、169を除外）、MOは47点数（163、166、169を除外）。空配列は欠損ではなく上がれない点数の表現なので維持。

JSONの7ルートは合法な例へ修正した。`routeText` と注記も同期。ブル表記は元データ互換のためJSON上は保持するが、アプリでは統一。合法性は検証済みだが、全ルートが競技上最善という保証はしない。例として128のMOはT18→T8→Bを使用。候補以外の合法回答も正解になる。

## 構成

- `practice-core.js`: DOMや保存機能から独立したルール判定・合法候補生成・点数帯・復習抽選。Nodeテストとブラウザーで共用。
- `app.js`: 既存の説明・候補・カスタム登録を維持し、画面操作と端末保存を担当。
- `tests/`: JSON全件・ルール・抽選の単体テストと、iPhoneサイズでのブラウザー統合テスト。

成績と設定は端末・配信元ごとのlocalStorageへ保存。クラウド同期はなく、Safariのデータ削除等で消える。ホーム画面版とSafariで保存領域の扱いが異なる場合があるため、実機で確認すること。

## 操作改善（追加変更）

ルール選択をページ最上部へ移動。全画面サイズでS/D/Tの3切替と共通1〜20の入力へ統一。「回答する」を押したときだけ採点・候補・解説を表示。指定点数はランダム出題範囲から独立し、2〜180の上がれない点数も学習できる。最初の狙いを外した場合の2本の合法例を計算し、上がれない場合は明示する。SWキャッシュをv3へ更新。

## 画面切り替えと出題順

練習、結果、解説、外した例、設定、成績、自分登録を専用画面へ分割。回答ボタンで結果へ、次へで次の問題へ移る。入力画面は小さいスマートフォンでも点数・20個の数字・回答操作が同時に収まるようにした。外した例と登録一覧はページ送り。出題順はランダムまたは範囲内の点数昇順（最後から先頭へ循環）。復習優先はランダムのみ。設定は既存保存キーへ追加し、成績・自分登録の互換性を保つ。SWキャッシュはv5。

## ボード入力と操作の統一

`dartboard.js` は標準の時計回りの数字配置とSVGの各得点エリアを描画し、タップ・キーボードから既存判定へ入力する。DOの外側ブルはSB、MO/SOではBULLとして扱う。ルール名はカタカナ、設定タブは右端。成績は既存の回答数・正解数から誤答履歴を算出し、正解後も間違えた点数を表示。外した例は全件を比較表示し、結果・解説・外した場合・次の問題の固定ナビゲーションを採用。端末の保存キーと構造は変更せず、SWキャッシュに新しいスクリプトを加えv6へ更新。

## タップ領域と判定表示の改善

ダブル帯を18から30、トリプル帯を14から28へ広げ、外側ブルの半径を20から30、内側ブルを9から16へ拡大（SVG座標）。得点と数字配置は維持。直前の選択は黄色の塗りと白い輪郭で強調。合法な候補外ルートも「正解」に統一し、大きく一度だけ表示。判定・成績保存は維持。外した例は1列で比較し、短い画面でも全例とナビゲーションが収まるよう調整。SWキャッシュはv7。
